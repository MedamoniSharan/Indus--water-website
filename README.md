> **Drink Better, Live Better** | Sourced from Turakapalem, Guntur | Available 24/7

Official frontend website for **INDUS Packaged Drinking Water**, built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

- 💧 **Hero Carousel**: Auto-playing dynamic carousel showcasing brand imagery, active lifestyle, family trust, and express 24/7 supply.
- 📱 **WhatsApp Add to Cart & Checkout**:
  - Quantity controls (`-` / `+`) and itemized pricing (500 ML, 1 Liter, 20L Bulk Can).
  - Add items to a persistent floating WhatsApp Cart.
  - Slide-out checkout drawer with live total calculation.
  - One-click checkout generating formatted order messages to `+91 9060234566`.
  - Instant WhatsApp single-item direct order button.
- 🎨 **Brand Identity**:
  - Crimson red & crystal water color theme (`#C8102E`, rose pinks, ice blue).
  - Official INDUS droplet logo emblem integrated in header, mobile drawer, and footer.
- 🚚 **Local Guntur Delivery**:

  - Email: `induswater2025@gmail.com`
  - Location: Turakapalem, Guntur (24/7 Express Service).
- 📱 **Fully Responsive**: Mobile-first design with smooth animated interactions.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MedamoniSharan/Indus--water-website.git
   cd Indus--water-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack
